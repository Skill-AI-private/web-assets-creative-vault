## Technical Specifications

`web-assets-creative-vault` equips coding agents with a structured asset selection hierarchy. It completely eliminates pixelated GIF files, mismatched icon sets, blurry raster PNGs, and broken external image URLs.

### Core Disciplines

* **Crisp Vector Standard:** Mandates inline or packaged SVG vector icons (`lucide-react`, `simple-icons`) with scalable stroke widths and optical centering.
* **Dynamic Palette Coupling:** Enforces CSS `currentColor` or theme variable mapping on vector illustrations so graphics immediately adapt to brand color palettes.
* **Sub-100KB Micro-Animations:** Replaces multi-megabyte GIF files with ultra-lightweight Lottie JSON animations rendered natively via canvas or SVG.
