## ⚡ Quick Install

### 🪟 Windows (PowerShell)
```powershell
git clone https://github.com/Skill-AI-private/web-assets-creative-vault.git "$HOME\.gemini\config\skills\web-assets-creative-vault"
```

### 🍎 macOS & 🐧 Linux (Bash)
```bash
git clone https://github.com/Skill-AI-private/web-assets-creative-vault.git ~/.gemini/config/skills/web-assets-creative-vault
```
